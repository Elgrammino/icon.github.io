# Иконки-буквы (3-й экран)

Сюда клади картинки для конкретных букв. Имя файла = сама буква (заглавная), формат PNG или JPG.

Примеры:
- `А.png`, `Б.png`, `М.png` — кириллица
- `A.png`, `B.png`, `M.png` — латиница
- `0.png` … `9.png` — цифры

Если для буквы файла нет — автоматически подставится сгенерированная иконка с этой буквой поверх цветного фона, ничего не сломается.

Рекомендации по картинке:
- квадратная, минимум 180×180 px
- можно с любым фоном — форма сквиркла (скруглённый квадрат) обрежется автоматически на сайте
- не нужно самому скруглять углы или добавлять тень — это сделает CSS
