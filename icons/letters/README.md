# Иконки-буквы (3-я страница)

Имя файла = буква (заглавная): `М.png`, `A.png`, `7.png`.
Для повторяющейся буквы в слове: `С_2.png`, `С_3.png` … (иначе будет та же картинка).

Если файла нет:
1. берётся похожая буква другого алфавита (кириллическая Н → латинская H и т.п.);
2. иначе рисуется сгенерированная иконка в том же стиле.

Сейчас есть: латиница A–M и кириллица А Б В Г Д Е Ё Ж З И Й К Л М П Р С Т У Ф Х Ц
(+ С_2, Ц_2). **Нет: Н О Ч Ш Щ Ъ Ы Ь Э Ю Я** — для них заглушка.

Подписи под иконками — «названия приложений» из `LETTER_NAMES` в `js/app.js`.

Картинка: квадрат 180×180 px, фон на всю площадь, без своих скруглений,
полей и теней. Оригиналы до обработки лежат в `icons/_originals/`.
