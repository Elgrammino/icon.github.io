# Иконки 1-го домашнего экрана

Список файлов и их порядок заданы в `js/app.js`, массив `SCREEN1_APPS`.
Просто положи сюда файл с точно таким именем, как указано в поле `file` —
например `messages.png` для «Сообщения» — и он подменит сгенерированную заглушку.

Текущий список (в порядке появления на экране):
messages.png, contacts.png, calendar.png, photos.png, files.png, notes.png,
clock.png, navigator.png, maps.png, reminders.png, appstore.png, settings.png

Чтобы изменить порядок, названия подписей или добавить/убрать иконку —
редактируется массив `SCREEN1_APPS` в `js/app.js`, а не эта папка.
